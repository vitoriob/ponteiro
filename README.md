# Ponteiro

App de manejo de confinamento de gado: leitura de cocho, trato e vagão, lotes com indicadores, sanidade, estoque de ração, capacidade dos currais, preços da arroba e simulador de compra.

Funciona no celular e no computador, inclusive sem sinal. Para instalar, abra o link do app no navegador do celular e escolha "Adicionar à tela inicial".

Os dados ficam salvos no próprio aparelho. A sincronização entre aparelhos ainda está em construção.
